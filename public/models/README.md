# Models 3D

Placez ici vos fichiers **GLTF / GLB**.

## Hero
- Rack serveur ou cube lumineux abstrait
- Sources : [Sketchfab](https://sketchfab.com) · [Polyhaven](https://polyhaven.com)

Le hero fonctionne déjà avec une géométrie procédurale (`FloatingServer`). Un modèle externe n’est pas obligatoire.

Exemple d’usage plus tard :

```tsx
import { useGLTF } from '@react-three/drei'

useGLTF('/models/server-rack.glb')
```
